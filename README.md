# Descrição do projeto

O sistema consiste em uma plataforma web para gestão e acompafnhamento dos horários e da carga horária dos docentes do DACOM. O sistema utilizará os dados de horários já coletados pelo departamento para centralizar consultas, análises, indicadores e relatórios

# Tecnologias utilizadas

### Linguagens: JavaScript, TypeScript
### 	Frameworks: React, NodeJS, Express
### Ferramentas de Desenvolvimento: VS Code
### Banco de Dados: MongoDB
### 	Infraestrutura/Outros: GitHub (Repositório) e Figma (Prototipagem)
### 	Gerenciamento de processos/tarefas: Project/Board Kanban do GitHub
